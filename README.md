# Dr. Chanique Cousins · Healthcare Business Analyst Portfolio

Live site: https://chancuz-hba.github.io/healthanalytics/

## Files
```
index.html                 ← all page content (edit text here)
assets/css/style.css       ← colours & fonts (see DESIGN TOKENS at top)
assets/js/main.js          ← typing headline, dark mode, menu, project filters, contact form
images/                    ← profile photo, project images, favicon, social share image
```

## Quick edits
- **Rotating headline phrases:** top of `assets/js/main.js` (`phrases` list).
- **Add a project:** copy an `<article class="card">` block in `index.html`. Set `data-tags` to `ba`, `data` and/or `product` so the filter buttons work.
- **Add a job:** copy a `<li class="job">` block in the Experience section.
- **Colours:** change `--accent`, `--warm` and `--teal` in `style.css`.
